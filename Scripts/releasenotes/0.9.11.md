- **Sovereignty board** — a new Universe screen with three tabs: **Campaigns** (active and upcoming sov battles with event type, countdown, defender and attacker alliances, and a live score bar), **Structures** (claimed TCUs and Infrastructure Hubs sorted by ADM, with vulnerability windows and an alliance filter), and **Holders** (top alliances by system count). Clicking any row opens a detail pane on the right — same click-to-inspect layout as Agent Finder and Market Browser — showing a full alliance card (ticker, member corps, founding date, executor), cross-referenced holder/ADM/active-campaign info, a Set Destination button, and zKillboard/Dotlan links.

- **Galaxy Map "Kills" mode** — a new colour mode that shades each constellation by ship and pod kills in the last hour, with the exact count shown in the constellation popover.

The top banner surfaces active maintenance and major incidents (not just "servers unreachable"), the Dashboard server card lists incidents, scheduled maintenance, ESI route health, and error-budget state, and the Diagnostic Logs pane shows a live "EVE Service Status" bar so an empty screen has a visible cause.
