Quality-of-life features
- Command palette (⌘K): a fuzzy quick-switcher over all ~50 navigation sections, with recents, quick actions (Settings, Add Character, Refresh), and live EVE name lookup via /universe/ids/ that jumps to the market window or opens Dotlan/zKillboard.
- Standard macOS menu + keyboard shortcuts: a new AppCommands scene adds an EVEOps/File/Go/Window/Help menu and wires ⌘K, ⌘R, ⌘0, ⌘[/⌘], ⌘1–9, ⌘N and ⌘, (the app previously had no menu bar and zero shortcuts).
- Last-viewed section is remembered across launches (plus a couple of filter toggles), instead of always resetting to the Dashboard.
- Unified refresh & freshness UI:  new shared RefreshButton, live "Updated 3m ago" label, .autoRefresh(every:) and .periodicTick(every:) modifiers, adopted across the main daily-use screens.
- Stale-while-revalidate loading: LoadingStateView now keeps cached content on screen with a thin progress strip (and an optional skeleton) instead of flashing a full-screen spinner on every navigation.
- Launch update check is now unconditional: it no longer depends on the "automatic checks" toggle, so an available version is found on every launch.
- Update notifications are reliable and actionable: posted from didFindValidUpdate (not just the gentle-reminder hook), carrying an "Install Update" action button, and checkForUpdates() now brings the app forward so the Sparkle window isn't buried.
- The menu-bar "Update available" banner dismisses the popover and launches the installer, with a clearer "Install" affordance.

Reliability & performance
- ESI response cache persisted to disk: the ETag cache is now mirrored to Caches/EVEOps/ and restored before the first prefetch, so relaunch serves fresh data instantly and revalidates the rest with cheap 304s.
- Shared cached image loader: a drop-in CachedAsyncImage (memory + disk) replaced all 130 AsyncImage call sites across 42 files, removing portrait/icon flicker and re-downloads.
- Better error handling
- First VoiceOver pass: labels/values/hidden-decoration added to the toolbar buttons, status/reauth banners, LoadingStateView states, the sidebar (portraits, pilot switcher, reauth, calendar badge), the command palette rows, the Dashboard hero card, and the Sovereignty score bars and Route-risk pill.
